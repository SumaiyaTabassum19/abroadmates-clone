ABROADMATES FRONTEND — WARM PALETTE UPDATE (NO BOOTSTRAP)

Palette:
  #A14646 — burgundy
  #DA6556 — coral
  #EB895B — orange
  #FDB773 — peach

Files:
  index.html
  css/style.css
  js/app.js

Installation:
1. Extract this ZIP.
2. Copy the included frontend folder into your AbroadMates project root, beside your backend folder.
3. If prompted, replace the existing frontend/index.html, frontend/css/style.css and frontend/js/app.js.
4. Start the backend from its folder using: npm run dev
5. Open frontend/index.html using VS Code Live Server (do not open it as file://).
6. The destination finder continues to call:
   GET http://localhost:5000/api/catalog/countries
   GET http://localhost:5000/api/catalog/countries/:countryId/universities

This version uses plain HTML, CSS and JavaScript. It does not include Bootstrap.
No backend or database changes are required for this visual update.
